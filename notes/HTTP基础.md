# http基础
## 请求数据的格式
- 请求行（请求方式，请求路径）    请求头（key：value） 请求体（post方式才有）-（get请求请求阐述在请求路径的”？“之后的）
## 响应数据的格式
	- 200---客户端请求成功
	- 400---请求参数错误
	- 404---请求资源不存在，url输入有误，或网站资源被删除了
	- 500---服务器发生了不可预期的错误
- 响应行（状态码）  响应头（key：value）   响应体
